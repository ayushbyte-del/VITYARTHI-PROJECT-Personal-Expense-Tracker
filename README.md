# Personal Expense Tracker

A simple Python CLI app built to help track daily spending, set monthly budgets, and see where your money goes.

---

## What this project does

Managing daily expenses manually can get chaotic quickly. This project is a command-line tool written in pure Python that helps you log daily expenses, organize them by categories, and analyze your spending habits. It includes validation to avoid invalid inputs and auto-generates short receipt codes for each transaction.

---

## Features

- **Add, View, Update, Delete Expenses:** 
- **Auto-generated Receipt Codes:** 
- **Spending Summary & Stats:** Displays total spent, average, median, min/max expenses, and top 3 biggest expenses.
- **Category Breakdown:** Group spending across `food`, `travel`, `shopping`, `bills`, `health`, `fun`, and `other`.
- **Budget Tracking:** Enter your monthly budget and check if you are within budget or overspending.
- **Saving Tips:** Built-in financial tips for better money management.
- **Sample Data:** Quickly load sample expenses to test features without manual entry.
- **Input Validation:** Error handling for invalid amounts, numbers, or unknown categories.
